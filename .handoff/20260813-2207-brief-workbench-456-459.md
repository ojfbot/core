## Ticket #456 — Zero-dependency rule: sidecar vs revise (grilling)

Run via `/grill-with-docs`. The operator rules; you record. Questions the grill must put
(survey open question 4 first — the sharpest):

1. Does "zero dependencies" mean **no package manager**, **no third-party bytes**, or
   **no runtime deps in the drill engine specifically**? A vendored ~377 KB CodeMirror
   file, a vendored ~13.5 MB Pyodide runtime, and an outside-the-repo `uv`-cached wheel
   set are three different answers; the current prose distinguishes none of them.
2. Scope of the rule: drill-engine core only (sidecar lab surface free to differ), or
   repo-wide? The sidecar option keeps the core untouched either way.
3. Enforcement: whatever is ruled, does a CI gate get built for it (extend ui-gate /
   new boundary script), and what exactly does it detect?
4. Does the ruling change CLAUDE.md's "Zero npm dependencies" line, and who owns that edit?
